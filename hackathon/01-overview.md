# Overview

**Build With AI: Basics** is the first hackathon in Devpost Learn. It is a short, beginner-friendly event built around one skill: stay in control of an AI-built project by planning before you code.

You build a proof of concept: a small app that runs and does one thing end to end. Active work is about **2–4 hours**. The result is a first working draft, plus a method you can reuse: the agent interviews you, writes the decisions down, and builds in reviewed steps.

## Why it exists

Prompting an agent to "just build it" often produces code that repeats a mistake you already fixed, forgets a decision from earlier in the chat, or runs while you still cannot explain it. This hackathon teaches a repeatable format so those gaps are smaller.

The email name for the format is **Orient → Plan → Build → Ship**. The installed skills are the six steps that carry that format. See [09-skill-pack-and-method.md](09-skill-pack-and-method.md).

## What you leave with

- A project you built during the submission period.
- Planning documents in the repo: `devpost/scope.md`, `devpost/prd.md`, and `devpost/spec.md`.
- A Devpost Learn badge for every eligible submission.
- A chance at the **$2,500** prize pool if the project is among the most complete and distinctive.

## How to begin

1. This folder already has the skill pack. See [12-workspace-setup.md](12-workspace-setup.md).
2. In Cursor or OpenCode, say `run 1-start`.
3. Join the Devpost Discord for questions, office hours, and other builders' projects. Event times are in [08-schedule-and-events.md](08-schedule-and-events.md).
4. Submit on Devpost before the deadline. The checklist is [05-submission-checklist.md](05-submission-checklist.md).
