# Submission checklist

Sources: Official Rules section 4, the hackathon overview, the Devpost updates page, and the organizer email. Form fields can change. If the live form disagrees with this list, follow the form and the Official Rules.

Submit at https://learn-ai-basics.devpost.com/ before **Monday, October 26, 2026, 5:00 pm Eastern Time**.

You write the project name, short description, skill-pack explanation, and exit-survey answers. During `6-ship`, the agent may interview you, point out gaps, and correct spelling and grammar. It does not draft or rewrite that copy.

## Required

- [ ] Registered on the hackathon site with a Devpost account.
- [ ] Project built during the submission period with the skill pack.
- [ ] `devpost/scope.md`, `devpost/prd.md`, and `devpost/spec.md` in the public repo, produced by the skills and approved by you.
- [ ] Project runs as the video and description show, with setup instructions in the repo.
- [ ] Open-source license file detectable in the repository About section. MIT `LICENSE` is already in this repo.
- [ ] **Public** GitHub, GitLab, or Bitbucket URL pasted in the **Try it out** field. Organizers use this link to confirm you used the curriculum and to decide prize eligibility. Reviewers are not expected to clone or run the code.
- [ ] Text description: what it does, who it is for, and what you learned.
- [ ] Short explanation of **how you used the Devpost Learn Skill Pack** (added as a required question; required for prizes).
- [ ] Age-of-majority checkbox (required for prizes).
- [ ] Demo video, publicly visible on **YouTube or Vimeo**:
  - Shorter than three minutes. Judges are not required to watch past three minutes. The overview asks for 1–3 minutes. A screen recording is enough.
  - Shows the project functioning on the device it was built for.
  - Third-party trademarks, copyrighted music, or other copyrighted material only if you have permission.
- [ ] All materials in English, or an English translation of the video, description, testing instructions, and other materials.
- [ ] If the app is private, login credentials in the testing instructions. Keep it free for judges through the end of judging (October 30, 2026, 5:00 pm ET).
- [ ] Secrets, credentials, and `devpost/learner-profile.md` reviewed before the repo is public. The profile is gitignored here. An ignore rule does not remove a file that was already committed.

## Optional

- A live deployment. It does not replace the video or the public repo URL.
- Peer feedback or a Discord post. If you post, you write it yourself. The updates page points people to `#devpost-learn-feedback` with project name, a one-line description, a link, and the kind of feedback you want.

## Before you click submit

- [ ] Try it out link opens the public repo without asking for a login.
- [ ] Video link plays without asking for a login.
- [ ] Planning docs are the real approved versions, with `status: approved` once you have signed off.
- [ ] You can explain the core path, because judges score a coherent product and a clear pitch. See [06-judging-rubric.md](06-judging-rubric.md).

Drafts can be saved on Devpost before the deadline. After October 26 at 5:00 pm ET, the submission is locked except for limited fixes Devpost allows.
