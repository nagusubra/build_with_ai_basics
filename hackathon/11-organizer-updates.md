# Organizer updates

Collected from the hackathon email and https://learn-ai-basics.devpost.com/updates as of October 12, 2026. Re-read the updates page before you submit. The form has already changed once.

## Email: make the project yours

Build With AI: Basics is the first Devpost Learn hackathon: shorter, one skill at a time, open to join on a monthly cadence. Beginner-friendly, about 2–4 hours, no prior AI-coding experience required.

The failure mode they name: the agent repeats a mistake you fixed, forgets a decision from ten prompts ago, or returns code that runs and that you cannot explain. The format they teach is **Orient → Plan → Build → Ship**.

Their start steps:

1. Install the skill pack, then run `1-start`. The agent interviews you so later steps use your answers. Installed in this repo.
2. Build an afternoon-sized proof of concept. Live build was October 1 at 1:00 pm ET (recording linked below). Cup of Joe office hours: October 6 and October 13, 3:00 pm ET, Discord.
3. Submit to earn the badge. Strong projects compete for cash. Deadline: October 26, 2026, 5:00 pm ET.

Completers get a Devpost Learn badge. Award winners share **$2,500**, a newsletter feature, and a social spotlight.

## Email and update: public repo in Try it out

The public GitHub, GitLab, or Bitbucket URL goes in the **Try it out** field on the submission form. Organizers use it to confirm you tried the curriculum. It is how you stay eligible for a prize. If you submit early, go back and check that field before the deadline.

## Update: two new required questions

Devpost added:

1. A short explanation of **how you used the Devpost Learn Skill Pack**.
2. An **age of majority** checkbox.

Both are required for prize eligibility. If you already submitted, open the submission, answer them, and save before October 26, 2026, 5:00 pm ET. While you are there, confirm the public repo link is in Try it out.

The same update notes that https://github.com/challengepost/learn-ai-basics is MIT. You may use, change, and include that skill pack. This project's own `LICENSE` is also MIT, which is what the rules want visible in the repository About section. The skill-pack license covers their curriculum files. Your `LICENSE` covers the project you build here.

## Update: feedback channel
